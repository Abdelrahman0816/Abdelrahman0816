## 👋 About me

I'm a Computer Engineering student at **KTH Royal Institute of Technology** in Stockholm, graduating in **2028**. I like turning ideas into working products, from low-level C to modern web apps.

- 🔨 Building **[SmartValGuiden.se](https://smartvalguiden.se)**, a Swedish electronics comparison site, now being rebuilt in **Next.js** and **React**
- 🎮 Co-developed **Reaper**, a networked 2D multiplayer survival game in **C** and **SDL2**
- 🤖 Running open-source AI models locally with **Ollama** to support my development workflow
- 🌱 Currently learning **Java** and **discrete mathematics**
- 🌍 Speaks Swedish, English, Arabic and some French
